# CHANGELOG

## Версия v0.1-inversion

- Базовая версия, реализующая **inversion pattern**. Генерация ADR разрешена только при наличии всех шести частей Y-Statement.
- При неполных данных задаётся один вопрос, перечисляющий все недостающие части.
- Уточняющие вопросы ограничены тремя попытками на один ADR.
- Если после третьего вопроса сведения неполные, ADR не создаётся.
